### Anti-Pattern #1 (Var with assignment)

This code example demonstrates the Var Usage anti-pattern. Specifically, it illustrates the `Var with assignment` case.

```javascript
var x = 1;
```

### Anti-Pattern #2 (Var only)

This code example demonstrates the Var Usage anti-pattern. Specifically, it illustrates the `Var only` case.

```javascript
var myVar;
```

### Safe #1 (Let)

This code example demonstrates a safe approach for the Var Usage issue. Specifically, it illustrates the `Let` case.

```javascript
let y = 2;
```

### Safe #2 (Const)

This code example demonstrates a safe approach for the Var Usage issue. Specifically, it illustrates the `Const` case.

```javascript
const z = 3;
```
